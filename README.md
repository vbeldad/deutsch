# Lern Deutsch · Aprende alemán

App para aprender alemán desde cero (nivel A1), con el mismo diseño que las apps de inglés, catalán y francés.

- `index.html`: portada animada.
- `exercices.html`: 10 lecciones con 71 ejercicios (escribir, elegir y escuchar). Debajo de cada pregunta aparece la traducción al español.
